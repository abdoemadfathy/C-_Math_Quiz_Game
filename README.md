# C++_Math_Quiz_Game
🔹 Console-Based Interactive Math Quiz Game (C++ Project)
I developed an interactive Math Quiz Game in C++ as a console-based application.

✨ Key Features:
🎯 Choose the number of questions, difficulty level (Easy, Medium, Hard, or Mixed), and operation type (Addition ➕, Subtraction ➖, Multiplication ✖, Division ➗, or Mixed).
⚡ Dynamically generates math questions and evaluates user answers in real-time.
📊 Provides instant feedback, score tracking, and a detailed final result summary at the end of the quiz.

🔧 This project enhanced my skills in C++ programming, control structures, enums, random number generation, and console UI design.
